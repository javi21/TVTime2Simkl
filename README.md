# 📺 TVTime2Simkl

> Preserve your TV Time history.

TVTime2Simkl is an open-source tool that converts your TV Time export into a Simkl-compatible import.

This project was created after the announcement of TV Time's shutdown to help users preserve years of watch history.

---

## ✨ Features

- 📺 TV Shows
- 🌸 Anime
- 🎬 Movies
- 📦 TV Time ZIP support
- ⭐ Simkl CSV export
- 📊 Watch statistics
- 🌍 English & Español
- ❤️ Open Source

## ❤️ Why?

Nobody should lose years of watch history because a service shuts down.

This project aims to make migration from TV Time to Simkl as simple as possible.
